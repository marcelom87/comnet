## Resumo do Projeto

As Redes Definidas por Software (do inglês Software-Defined Networking - SDN) representam um moderno conceito de arquitetura separando o plano de dados e controle da rede. Devido a esta característica, novos desafios de segurança são introduzidos neste modelo de rede em virtude das fragilidades existentes entre os planos. Este projeto de pesquisa explora a utilização de técnicas de Machine Learning - ML para propor mecanismos de segurança em ataques distribuídos de negação de serviço para SDNs.Neste sentido, este projeto propõe o uso de métodos estatísticos existentes combinados a técnicas de ML com o objetivo de melhorar a acurácia das estratégias de detecção sem comprometer o desempenho na mitigação de ataques DDoS em SDNs. O uso dessa abordagem resultará no desenvolvimento de técnicas mais eficientes na mitigação de ataques DDoS, minimizando os impactos causados por estes ataques e contribuindo para a melhoria no tráfego de rede SDN..
