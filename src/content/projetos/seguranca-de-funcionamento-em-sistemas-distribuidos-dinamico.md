## Resumo do Projeto

Este projeto propõe o desenvolvimento de protocolos para a solução de problemas fundamentais encontrados no projeto de aplicações distribuídas. Estas soluções estarão voltadas para os ambientes dinâmicos, onde a composição e a topologia do sistema podem sofre mudanças arbitrárias. Além disso, tais soluções devem prover os atributos de confiabilidade, disponibilidade e integridade para as aplicações que as utilizarem. Este projeto foi desenvolvido durante o estágio de doutorado sanduíche, do doutorando Eduardo Alchieri, na Universidade de Lisboa - Portugal, junto ao grupo de pesquisa Navigators..
