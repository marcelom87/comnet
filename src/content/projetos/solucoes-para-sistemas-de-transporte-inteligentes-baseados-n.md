## Resumo do Projeto

Um sistema de transporte inteligente integra dados, comunicação e computação para resolver diversos problemas nos sistemas de transportes tradicionais de grandes cidades, tais como engarrafamentos e acidentes, visando, por exemplo, diminuir o tempo de viagens e aumentar a qualidade e segurança dos deslocamentos. Dessa forma, uma solução eficiente para um sistema de transporte inteligente deve ser capaz de integrar diversas fontes de dados urbanos, dentre elas dados provenientes de redes veiculares e dados da Web sobre diversas questões da cidade. Ações nessa direção ilustram uma emergente área de estudo, denominada computação urbana. Este projeto tem como objetivo avançar o estado da arte da computação urbana provendo soluções para sistemas de transportes inteligentes que integra dados urbanos da Web e redes veiculares. Para isso, o projeto irá investigar novas técnicas para a coleta, integração e análise de grandes volumes de dados provenientes de diferentes fontes, bem como propor mecanismos de disseminação, extração de conhecimento e controle de informação para aplicações em sistemas de transporte inteligente. Por fim, salienta-se que este projeto está vinculada ao projeto temático financiado pela FAPESP (processo, 2015/24494- 8)..
