## Resumo do Projeto

Este projeto de pesquisa teve início desde o doutoramento em Leeds/Inglaterra com a definição de um framework de estruturação automática de informação na Web. O framework é baseado em dois aspectos principais: linkagem dinâmica de conteúdos na Web e raciocínio espacial com uso de lógica topológica. Através de implementações de buscadores automáticos inteligentes é possível a associação semântica de assuntos na Web de acordo com tipos de relacionamento de conteúdos, tais como: igualdade, própria parte, sobreposição e desconexão..
