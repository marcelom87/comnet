## Resumo do Projeto

O principal enfoque deste projeto é desenvolver uma estrutura de processamento e de extração de informações, de forma a automatizar o reconhecimento de dados significativos (entidades nomeadas e relacionamentos) em fontes abertas oficiais mediante o uso de aprendizado de máquina e processamento de linguagem natural. Visando atingir este objetivo, os seguintes resultados serão o foco do esforço de pesquisa: a) o desenvolvimento de estrutura de coleta de acordo com a fonte de dado oficial; b) a pesquisa e desenvolvimento de modelo de aprendizado de máquina baseado em LLM; c) o desenvolvimento de estrutura de processamento de dados utilizando processamento de linguagem natural; e d) o desenvolvimento de solução de visualização de dados usando estruturas de dados orientado a grafos..
