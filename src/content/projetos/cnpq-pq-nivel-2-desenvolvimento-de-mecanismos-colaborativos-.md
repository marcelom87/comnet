## Resumo do Projeto

Este projeto tem como o objetivo principal o estudo e desenvolvimento de técnicas que permitam realizar o acesso dinâmico do espectro. Este acesso será desenvolvido com base na colaboração dos usuários secundários. Mais precisamente, este projeto visa o estudo e a elaboração de mecanismos de acesso ao meio colaborativos e eficientes em energia que permitam realizar as tarefas de sensoriamento, identificação de oportunidades de transmissão e o agendamento de transmissões. Como objetivo secundário, pretende-se desenvolver mecanismos de roteamento otimizados pela interação entre as informações da camada enlace (informações do meio) e da camada de rede de forma a desenvolver protocolos de roteamento para dispositivos que realizam o acesso oportunístico do espectro..
