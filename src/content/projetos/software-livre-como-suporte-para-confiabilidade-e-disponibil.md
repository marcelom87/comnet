## Resumo do Projeto

O objetivo geral deste projeto é o desenvolvimento de suportes de middleware para aplicações distribuídas com requisitos de qualidade de serviços tais como confiabilidade e disponibilidade. Partindo de nossas experiências anteriores com CORBA o projeto visa continuar o desenvolvimento de novas soluções para a programação distribuída, envolvendo modelos que integrem às características de objetos distribuídos às qualidades citadas. Este é desenvolvido em cooperação com o Departamento de Automação e Sistemas (DAS) da UFSC, tendo o professor Joni da Silva Fraga como coordenador geral do projeto..
