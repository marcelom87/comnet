## Resumo do Projeto

Objetivo Geral: - Contribuir para a melhoria dos processos de gestão da contratação dos montantes de uso do sistema de transmissão por ponto de conexão com a rede básica. - Minimizar o risco de sobre ou subcontratações a serem realizadas pela concessionária advindo uma menor tarifa para o consumidor. Objetivos Específicos: - Desenvolver uma metodologia para previsão dos valores dos montantes de uso do sistema de transmissão por ponto de conexão com a rede básica. - Desenvolver uma metodologia para monitoramento e gerenciamento das possíveis ultrapassagens das demandas dos valores contratados. - Desenvolver um sistema computacional baseada em Sistemas Inteligentes que implemente a metodologia para previsão dos valores dos montantes de uso do sistema de transmissão por ponto de conexão com a rede básica. - Formar uma base de dados consistente para projeções e para as futuras contratações dos montantes de uso por ponto de conexão da Distribuidora com a rede básica. - Implantar esse sistema computacional na concessionária..
