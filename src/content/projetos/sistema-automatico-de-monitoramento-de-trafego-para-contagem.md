## Resumo do Projeto

Este projeto tem por objetivo geral o desenvolvimento de um sistema portátil baseado em visão computacional para a contagem do fluxo de veículos, com identificação dos mesmos, em vias rodoviárias visando viabilizar estudos de contagem em cordão e em linha. OBJETIVOS ESPECÍFICOS Realização automática das seguintes tarefas: 1. Monitoramento com múltiplas câmeras ? Determinação da área, localização e posicionamento das câmeras ? Aquisição dos vídeos por longos períodos de tempos ? Processamento dos vídeos por computação distribuída 2. Processamento de Vídeo ? Detecção de veículos ? Localização da traseira ? Segmentação da placa ? Reconhecimento dos caracteres 3. Processamento de Dados ? Desenvolvimento de banco de dados multimídia ? Desenvolvimento de banco de dados de tráfego ? Mineração de Dados 4. Elaboração de Matrizes Sintéticas de Origem/Destino ? Desenvolvimento de procedimento para obtenção de matrizes O/D ? Desenvolvimento de procedimento para correção de matrizes O/D ? Desenvolvimento de procedimento para previsão de matrizes O/D 5. Geração de Relatórios.
