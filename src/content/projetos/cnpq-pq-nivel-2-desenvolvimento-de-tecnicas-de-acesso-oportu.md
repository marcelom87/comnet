## Resumo do Projeto

Objetivo deste projeto está no desenvolvimento de protocolos e algoritmos que permitam a alocação oportunista do espectro de forma dinâmica e eficiente, isto é, sem prejuízo para os usuários primários e permitindo o acesso de forma justa entre os usuários secundários..
