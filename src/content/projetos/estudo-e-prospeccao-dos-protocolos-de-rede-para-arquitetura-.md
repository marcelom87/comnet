## Resumo do Projeto

O estudo proposto neste documento visa prover elementos que servirão de base para o melhoramento tecnológico da família de roteadores desenvolvidos pela Digitel S/A. Este trabalho também tem como objetivo a continuidade do convênio firmado, desde 2009, entre as duas instituições, bem como, a continuação no processo de formação de profissionais nesta área aplicada de redes de computadores..
