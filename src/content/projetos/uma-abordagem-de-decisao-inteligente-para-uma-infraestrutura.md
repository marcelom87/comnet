## Resumo do Projeto

Nos últimos anos, um dos principais desafios globais está relacionado com a eficiência energética, sendo o desperdício de energia um dos fatores a ser destacado. Tal desperdício pode ser superado com o uso do Sistema de Automação Residencial (HAS). Contudo, as HASs são fortemente dependentes da sua rede interna, visto que esta é a base de uma casa inteligente. Nesse cenário, a Rede de Sensores e Atuadores sem Fio (RSASF) é uma solução promissora, ubíqua e de fácil implantação para ser utilizada como infraestrutura em um sistema de automação residencial. Entretanto, o uso das RSASFs como infraestrutura para monitorar e atuar no processo de decisão no contexto de um sistema de automação residencial traz novos desafios. Tais desafios remetem não apenas a falta de um método para atuar no processo de decisão dentro da própria rede para reduzir o consumo de energia dos moradores, mas também na ausência em investigar um trade- off entre precisão das informações e consumo de energia dos sensores para prolongar o tempo de vida útil da infraestrutura. Além disso, a falta de uma infraestrutura totalmente distribuída, flexível e que atenda às necessidades dos moradores são algumas das novas problemáticas a serem exploradas. Nesse contexto, este projeto de pesquisa visa propor um sistema de automação residencial distribuído usando nós sensores e atuadores sem fio. Para tanto, soluções baseadas em métodos de aprendizagem de máquina para atuar no processo de decisão dentro da própria rede, bem como soluções de agregações de dados serão propostas. Assim, o sistema será ciente não apenas no tempo de vida útil da rede, mas também no consumo de energia elétrica dos moradores. Ainda, mediante os dados distribuídos, serão reutilizadas as grandezas físicas do ambiente, tais como presença, temperatura e umidade, para correlacionar as aplicações (ar condicionado e/ou iluminação, por exemplo) no processo de decisão. Por exemplo, o sistema de ar condicionado pode desligar ou aumentar a temperatura, quando o sistema de iluminação detecta ausência de moradores no ambiente..
