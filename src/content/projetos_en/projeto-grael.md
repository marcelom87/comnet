## Project Overview

Project for the development and implementation of an innovative application in the mobility segment for cell phones to adapt WEB content to computationally limited mobile devices. Using the full potential of the Java, J2EE and J2ME platforms, a software architecture will be created to enable the viewing of HTML pages from the Internet on cell phones. Based on e-PING, a document that defines electronic government interoperability standards, the aim is to reuse all services already available on the Network and save money for public coffers by avoiding rework in the development of a range of systems.
