## Project Overview

Projeto para o desenvolvimento e implementação de aplicação inovadora no segmento de mobilidade para telefones celulares para adequação de conteúdo WEB a dispositivos móveis computacionalmente limitados. Utilizando todo o potencial das platagormas Java, J2EE e J2ME, será criada uma arquitetura de software para possibilitar a visualização de páginas HTML da Internet em aparelhos celulares. Baseado no e-PING, documento que define padrões de interoperabilidade do governo eletrônico, busca-se o reaproveitamente de todos os serviços já disponíveis na Rede e a economia aos cofres públicos na medida em que se evita o retrabalho de Development of uma gama de sistemas..
