## Project Overview

Applications running on distributed systems like grids are made up of sets of smaller programs called tasks. These tasks may or may not have dependencies on each other. The problem studied in this project seeks to meet the temporal requirements of applications made up of dependent tasks, since the execution of these applications is subject to the use of network links due to the need for dependency data to be transferred.
