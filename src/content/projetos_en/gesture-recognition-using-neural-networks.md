## Project Overview

Study and development of computer vision techniques for the efficient extraction of relevant features for the automatic recognition of manual gestures. A new neural network structure was also developed, called T-CombNET, dedicated to the processing of temporal information. The application of the techniques developed, such as feature extraction using morphological PCA and the T-CombNET neural network, allowed the creation of an automatic real-time system for translating manual spelling of Japanese and American sign languages ​​into text.
