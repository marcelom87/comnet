## Project Overview

This project aims to develop an automatic translation system from the Brazilian language of signs into text. Voice and gestures are the basic forms of communication used by man. Therefore, studies that allow the computer to see and hear are very important for progress towards creating a system capable of interacting naturally with human beings. In this work, computer vision techniques will be used to describe a time series of feature vectors, which are analyzed and classified by a neural network.
