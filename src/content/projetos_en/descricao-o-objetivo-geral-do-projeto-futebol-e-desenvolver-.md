## Project Overview

GT-CoLisEU, in its first phase, aimed to create a collection and monitoring system based on the emerging Mobile Cloud Computing paradigm, to analyze the quality and user experience in wireless networks. The developed system uses data collection techniques, cloud computing and visualization of large volumes of data. These techniques were combined in the implementation of three modules called Collector, Gateway and Manager. Collector is an application for mobile devices, with the function of obtaining information on network quality of service and quality of user experience. The Gateway was developed with the aim of forwarding a large amount of information received from numerous mobile applications to be computed in the cloud. Finally, this information is summarized by the Manager using visualization techniques, such as heat maps and histograms. The system developed by GT-CoLisEU was presented on several occasions (CT-Mon, WRNP and at the technology transfer seminar) encouraging discussions and suggestions for proposals for continuing the work. In this way, the three main continuity proposals of GT-CoLisEU are: (i) integrating the system developed with the IPÊ network MONITORING service, to carry out end-to-end monitoring, i.e., including the user's device and its experience, (ii) providing, in the Manager module, an audit process of the EDUROAM network, to analyze the quality of the network's access points and (iii) improving the Collector interface, allowing the use of the system by lay users.
