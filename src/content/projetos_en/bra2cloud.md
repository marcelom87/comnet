## Project Overview

Cloud computing has been used as the primary IT solution alternative to provide scalable, reliable and pay-per-use resources and services on-demand, including trusted servers and transient servers.The implementation of fault-tolerant approaches that ensure the reliability and the services continuity becomes a major requirement for users that want to effectively explore cheaper transient servers. This project investigate and propose a multi-agent framework to provide a transparent and resilient environment on transient servers by using multiple fault- tolerant strategies called BRA2Cloud (Brand new Resilient Agent-based Architecture for Cloud computing). The proposed framework uses a reasoning process to predict failure events helping to adjust fault tolerance plans and parameters. The framework includes elements to recognize the transient server environment, being useful to identify risks to the current server?s availability, achieving better levels of reliability reducing the total cost and execution time..
