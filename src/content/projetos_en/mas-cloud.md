## Project Overview

Dynamic provisioning of computational resources in cloud platforms is a challenging problem. In this scenario, multiagent system technology offers improvements using intelligent agents to dynamically choose the best computational load distribution reducing execution time and cloud services cost. This project presents MAS- Cloud, a multiagent system to dynamically monitor, predict and provide computational resources in cloud platforms. Using deductive reasoning agents to cooperatively act in a three layer architecture, it is provided transparent horizontal elasticity of virtual machines in publiccloud platforms (i.e., Google, Amazon EC2). MAS-Cloud was evaluated with an agent- based simulator called MASE-BDI that is a nondeterministic and CPU intensive application providing a challenging validation case. A multiple linear regression model wasused presenting good predictions with reduced mean absolute percent error (MAPE) of 3.59 CPU usage and 5.28 of execution time in the Google platform, and similar results in the Amazon EC2 platform..
