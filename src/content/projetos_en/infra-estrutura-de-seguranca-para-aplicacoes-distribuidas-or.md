## Project Overview

This project proposes a security infrastructure that, using various specifications and proposals, can guarantee the security of service-oriented applications. This infrastructure, in addition to guaranteeing basic security properties such as integrity, confidentiality, authenticity and availability, will enable the transfer of authentication between different administrative domains, even if they are using different security technologies. Trust services are also an objective in this project: access authorization can be delegated, even across administrative domains. These transfers of authentication and authorizations across domains must be based on a trust model to be defined. This infrastructure will be tested in two applications: a Web Portal application and a Multi-Party Decoupled Communication System.
