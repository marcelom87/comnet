## Project Overview

The popularization of applications such as autonomous vehicles, video streaming, augmented/virtual reality demands the creation and management of services that optimally use the computing resources present in edge and cloud computing infrastructures. These infrastructures are the result of the combination of devices ranging from those in the hands of the end user (smart phones, tablets and laptops), through servers deployed at the edge of the network and extending to cloud computing platforms. This wide range of heterogeneous devices provides diverse computing resources across a continuous spectrum, ensuring low network latency for services deployed on devices close to the end user and an illusion of unlimited resources on cloud devices. Therefore, for these applications to establish themselves and explore the full potential of computational resources that we can offer, it is necessary to develop solutions that adapt, at run time, to exploit the best of each computational resource present in the continuum. In this context, this project aims to innovate in four main aspects in the construction of distributed applications for the continuum, they are: adaptation mechanisms to support the mobility of stateful services, holistic monitoring of services running in edge and cloud computing infrastructures, machine learning techniques to guide the adaptation of services at runtime, and finally, collaborative machine learning techniques in scenarios with multiple services competing for computational resources on the same infrastructure. This project is expected to develop a framework, a domain-specific language (DSL) and machine learning algorithms that support the creation, deployment and management of autonomous and stateful applications in edge and cloud computing infrastructures.
