## Project Overview

CNPq Project - Universal Notice - Range A - Number 457272/2014-7: lThis project contemplates the development of adaptive algorithms, capable of handling changes that occur in the composition of quorum systems, allowing the application to be reconfigured at run time, so that the reading and writing protocols in the register are decoupled from the reconfiguration protocols. This property is fundamental to guarantee good system performance.
