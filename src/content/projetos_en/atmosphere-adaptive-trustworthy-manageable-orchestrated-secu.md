## Project Overview

(Adaptive, Trustworthy, Manageable, Orchestrated, Secure, Privacy-assuring, Hybrid Ecosystem for Resilient Cloud Computing) is a collaborative proposal presented in response to the EUB-01-2017 call on Cloud Computing, which addresses "critical aspects of cloud computing, including enhanced security and privacy; trusted clouds; resource pooling; data management and traceability; virtualization; and hybrid systems". These objectives are addressed in the context of an intercontinental experiment carried out on cloud computing infrastructures in Brazil and Europe. Furthermore, as stated in the EUB-01-2017 call, the developments focus "on the challenges of different application domains in business and social contexts". Finally, as also emphasized in the call, an additional focus is to contribute to standardization, interoperability and data portability. The main outcome of the project will be the design and implementation of a framework and platform based on lightweight virtualization, hybrid resources and federated infrastructures from Europe and Brazil to develop, build, deploy, measure and evolve reliable applications enabled to run in the cloud.
