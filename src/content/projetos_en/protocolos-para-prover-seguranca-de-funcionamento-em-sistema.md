## Project Overview

The main objective of this project is to develop algorithms for solving problems in dynamic distributed systems (DDS), taking into account security and reliability requirements. Some problems and models of distributed systems should focus our efforts. The consensus problem is a fundamental part of building safe distributed applications and, therefore, will be the subject of study. Furthermore, we intend to develop protocols to provide shared memory in SDD through Byzantine Quorum Systems. It is also intended to study concepts and protocols involving State Machine replication in SDD.
